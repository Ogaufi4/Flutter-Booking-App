# Review Method

Inspect the screen in grayscale first.

The most important element should still be clear without color.

Ask:

1. What does the eye see first?
2. Is that the correct product priority?
3. Are there too many containers?
4. Are unrelated elements too close?
5. Are related elements too far apart?
6. Is the image large enough to sell the destination?
7. Is the primary action visually obvious?
8. Is accent color being overused?
9. Does every border have a purpose?
10. Could one element be removed without harming usability?

# Failure Conditions

The layout fails when:

- all sections have equal weight
- every item is inside a card
- the screen contains many different radii
- the page uses several strong accent colors
- typography has too many sizes
- major headings are crowded against controls
- card images are too small to create emotion
- the primary action is only an outline
- empty states look like backend failures
