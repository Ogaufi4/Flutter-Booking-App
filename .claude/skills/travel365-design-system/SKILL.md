# Design Principles

1. The interface must have one dominant action.
2. Empty space is an intentional design element.
3. Photography carries more visual weight than decoration.
4. Orange is an accent, not the dominant UI color.
5. Deep navy anchors primary actions.
6. Off-white backgrounds create hospitality warmth.
7. Borders and spacing are preferred over strong shadows.
8. Serif typography is reserved for editorial headings.
9. Controls use sans-serif typography.
10. Repetition and consistency create the premium feeling.

# Button Selection

Use a primary dark button when the action moves the user forward in the main journey:

- Book any trip
- Continue
- Submit booking
- View availability
- Book your first trip

Use a secondary outlined button for useful but optional actions:

- Add to favourites
- View details
- Change
- Retry when another major action remains

Use a text button for lightweight actions:

- View all
- Edit
- Skip
- Cancel

Never place two visually equal primary buttons beside each other.

# Spacing

Use the shared spacing tokens.

Do not reduce spacing merely to show more content above the fold.

Luxury depends on clear visual grouping and deliberate breathing room.
