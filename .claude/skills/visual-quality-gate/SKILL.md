# Acceptance Checklist

- One clear focal point
- One clear primary action
- Shared screen padding
- Shared typography
- Shared radii
- Shared icon style
- Correct image proportions
- No excessive shadow
- No excessive accent use
- Adequate empty space
- Consistent section spacing
- No technical error copy
- No unnecessary cards
- No tiny controls
- No accidental visual imbalance

# Score

Score each category from 1 to 5:

```text
Hierarchy
Spacing
Typography
Photography
Button priority
Consistency
Responsiveness
Accessibility
State handling
Premium feeling
```

A screen must score at least 42/50, with no category below 4, before approval.
